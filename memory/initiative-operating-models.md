# Initiative Operating Models

- **Status:** Current
- **Domain:** Shared
- **Knowledge type:** Memory
- **Owner:** Executive sponsor / product owner role; individual assignment is pending
- **Last reviewed:** 2026-08-05
- **Sources:** [`shared model`](../docs/initiative-operating-model.md), [`Padel model`](../business/padel/operating-model.md), [`Phoenix model`](../business/phoenix/operating-model.md), [`China model`](../business/china/operating-model.md)

Padel, Phoenix, and China initiatives use a shared intake, assessment, authorization, execution, review, and closure-or-scale lifecycle. Each active initiative requires an accountable sponsor and owner before leaving assessment, evidence-based outcomes, explicit stop conditions, and a documented handoff or closure.

Durable constraints:

- Unknown owners, budgets, markets, partners, and targets must remain explicit unknowns until assigned or verified.
- Padel work validates the need and highest-risk operating assumptions through bounded pilots.
- Phoenix work must improve a project success metric or remove a verified measurement blocker, with Vertical 1 remaining the near-term focus.
- China work begins with sourced research and requires qualified review for applicable legal, regulatory, tax, data, licensing, and intellectual-property questions.
- External commitments, spending, publication, protected-data sharing, and production changes require explicit authority.
