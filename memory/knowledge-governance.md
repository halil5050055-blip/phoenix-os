# Knowledge Governance

- **Status:** Current
- **Domain:** Shared
- **Knowledge type:** Memory
- **Owner:** Engineering maintainer role; individual assignment is pending
- **Last reviewed:** 2026-08-05
- **Source:** [`docs/knowledge-taxonomy.md`](../docs/knowledge-taxonomy.md)

Phoenix OS classifies durable content by knowledge type, business domain, lifecycle status, and evidence state. Full content belongs in its canonical domain location; memory retains only continuity-critical context and links to canonical detail.

Durable constraints:

- Update an existing canonical source instead of creating a conflicting copy.
- Label facts, reports, inferences, assumptions, proposals, and unknowns accurately.
- Keep transient progress and execution details in task records rather than memory.
- Update indexes and supersession links in the same change as the content they describe.
- Data sensitivity, retention, and access control remain deferred to their dedicated governance milestone.
